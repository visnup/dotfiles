## Behavior

Be concise and direct in your explanations and responses.

## Code

Use TypeScript.
Prefer modern JavaScript features like async/await, template literals, destructuring, and spread syntax.
Propose small, simple solutions over complex, complete ones.
Write concise, compact, clever code over verbose, pedantic code:
  - Use single letter variables when their usage is obvious
  - Use arrow functions with immediate returns if possible
  - Skip explicit brackets ({}) when possible
  - Rely on implicit instead of explicit types
  - Chain calls like `.on(...).on(...)`, if an API supports it
